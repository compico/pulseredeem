# PulseRedeem

PulseSync addon: Twitch Channel Points → Яндекс Музыка → очередь PulseSync. Аддон получает события Twitch напрямую и добавляет выбранные треки в конец очереди плеера. Отдельный Node.js-сервер, локальные порты и веб-панель не нужны.

## Что потребуется

- Windows 10/11 и PulseSync с совместимым WebHost/Runtime.
- Яндекс Музыка Desktop с работающим PulseSync.
- Node.js 22.12+ только для сборки/разработки аддона.
- Twitch Developer Application, зарегистрированное как **Public client**.

## Установка

1. Установи Node.js 22.12 или новее.
2. Склонируй репозиторий или скачай ZIP и распакуй его **в отдельную папку вне каталога PulseSync** — например, `C:\\Users\\<имя>\\Documents\\GitHub\\pulseredeem`. Не размещай исходники внутри `%APPDATA%\\PulseSync\\addons\\pulseredeem`: эта папка предназначена только для установленной копии аддона.
3. Открой PowerShell в корневой папке проекта (там, где лежит package.json).
4. Выполни **npm install**.
5. Выполни **npm run dev** и оставь это окно открытым. Команда собирает аддон в %APPDATA%\\PulseSync\\addons\\pulseredeem и следит за изменениями.
6. Перезапусти PulseSync или обнови его интерфейс (Ctrl+R), если аддон не появился сразу. Ищи PulseRedeem в разделе установленных аддонов, а не в каталоге магазина.

Для однократной установки без режима наблюдения используй **npm run build**, затем **npm run sync**. После этого перезапусти PulseSync.

7. Открой настройки аддона PulseRedeem в Яндекс Музыке и найди раздел **Интеграции**. Переключатель **Обрабатывать заявки Twitch Channel Points** включает или выключает добавление треков из заявок. Для подключения Twitch используй действие **Подключить Twitch** в шапке PulseSync. Client ID уже встроен в аддон; Client Secret не используется. В уведомлении появятся код и ссылка активации Twitch. Подтверди доступ в браузере.
9. После авторизации выбери существующую награду Channel Points или создай новую прямо в окне PulseSync. Новая награда будет создана с обязательным текстовым вводом.
10. Попроси зрителей вставлять в поле награды прямую ссылку на трек Яндекс Музыки. Чтобы изменить выбранную награду, используй действие **Настроить награду** в шапке PulseSync. Чтобы отключить аккаунт, используй **Отключить Twitch** там же.

## Настройка приложения Twitch

В Twitch Developer Console приложение PulseRedeem зарегистрировано как **Public client** (без Client Secret). Client ID встроен в аддон. PulseRedeem запрашивает разрешения **channel:read:redemptions** и **channel:manage:redemptions**: первое нужно для чтения списка наград, второе — для создания награды.

В поле **OAuth Redirect URLs** укажи `http://localhost`, если Twitch Developer Console требует URL. Успешный OAuth Device Code Flow не использует redirect URL и не требует callback-сервера; Twitch может вернуть пользователя на этот адрес при отказе/отмене авторизации.

Используется OAuth Device Code Flow: аддон показывает одноразовый код, а подтверждение происходит на странице Twitch. Токены хранятся в локальном хранилище PulseSync, а не в файлах проекта. Refresh token Device Flow одноразовый и ротируется при обновлении — новая версия сохраняется сразу.

Аддон проверяет токен при запуске и далее раз в час через Twitch /oauth2/validate. Мы не зашиваем срок жизни токена: если Twitch вернёт 401, аддон использует refresh token и сохраняет его новую одноразовую версию. Public-client refresh token может стать недействительным после 30 дней без использования; если Twitch отклонит обновление или пользователь отзовёт доступ, подключи Twitch заново.

## Формат заявки

В поле ввода награды нужно отправить прямую ссылку на трек, например:

https://music.yandex.ru/album/123456/track/789012

Поддерживаются домены music.yandex.ru, music.yandex.com, music.yandex.kz и music.yandex.by. Ссылка должна вести на конкретный трек, а не на альбом или плейлист.

После получения погашения аддон проверяет ссылку и вызывает SDK PulseSync addTrackToQueueById(trackId, { albumId, position: 'last' }). Повторные EventSub-события с тем же redemption ID отсекаются.

## Команды разработчика

| Команда | Назначение |
| --- | --- |
| npm run dev | Сборка и доставка аддона в PulseSync в режиме разработки |
| npm run build | Production-сборка |
| npm run sync | Копирование собранного аддона в каталог PulseSync |
| npm test | Unit-тесты |

npm start отсутствует намеренно: PulseRedeem работает внутри PulseSync.

## Ограничения текущей версии

- Веб-панели и отдельной очереди заявок нет: трек добавляется сразу в очередь PulseSync. Обрабатываются только заявки выбранной награды.
- Аддон не меняет статус погашения награды на Fulfilled автоматически.
- Нужна проверка WebSocket/EventSub в установленной версии PulseSync: SDK 0.18.0 документирует HTTP-сетевые запросы, но не предоставляет отдельный WebSocket-метод. Используется стандартный WebSocket API среды WebHost; совместимость CSP/сетевых разрешений должна быть подтверждена smoke-тестом.
- Совместимость SDK 0.18.0 с конкретной версией PulseSync нужно проверить в самом приложении.
